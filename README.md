## 📌 About

This is my personal portfolio website where I showcase my skills, projects, and experience as a software developer.

The website is fully responsive, supports Arabic and English languages, includes dark mode, smooth animations, and a modern user interface.

## ✨ Features

- Responsive Design
- Arabic & English Languages
- RTL / LTR Support
- Dark & Light Mode
- Smooth Animations
- Project Gallery
- Skills Section
- Contact Section
- Modern UI/UX
- Fast Loading
